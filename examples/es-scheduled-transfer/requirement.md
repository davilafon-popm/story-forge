# Programadas › Cuentas a terceros › Recurrente (ficticio)

- El cliente puede programar una transferencia recurrente a una cuenta de terceros inscrita.
- Frecuencias: semanal, quincenal, mensual.
- Fecha de inicio: desde el día siguiente. Fecha de fin opcional; si se indica, debe ser posterior a la de inicio.
- El monto se valida contra el límite diario del cliente (servicio "Consulta de límites").
- La programación se registra con el servicio "Registro de programaciones". Sin confirmación del servicio no se muestra éxito.
- Comisión: [por definir con negocio].
