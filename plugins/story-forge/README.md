# story-forge plugin

Skills (`skills/`), subagents (`agents/`), templates and Given/When/Then keywords (`templates/`), starter knowledge base (`knowledge-base/`) and tool categories (`CONNECTORS.md`).

Install (Claude Code 2.1.275 or later):

```
/plugin install story-forge --marketplace davilafon-popm/story-forge
```

Then start with: "set up story-forge" (skill `sf-setup`). Full documentation in the repository root README.
