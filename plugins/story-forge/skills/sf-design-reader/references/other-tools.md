# Other design tools

The strategy chain is the same; only the mechanics change. Contributions with scripts or step-by-step guides are welcome.

| Tool | Texts | Images | Notes |
|---|---|---|---|
| Penpot | Its API (Penpot is open source and can be self-hosted) or an MCP if available; exported SVG keeps texts | API export or designer export | On self-hosted instances the team controls access and limits |
| Sketch | Local `.sketch` file is a zip with JSON pages (readable without network) | Designer export (slices) or `sketchtool` on macOS | — |
| Adobe XD | Designer export or shared-link specs | Designer export | Product in maintenance mode; prefer designer export |
| Any tool | `manual`: the user pastes texts or shares a spec export | `designer-export`: folder of PNGs named by screen | Always works |

When adding a tool, document: how to identify a screen (node/frame id), how to build a link to it, how to read its texts, how to export one PNG per screen, and its limits.
